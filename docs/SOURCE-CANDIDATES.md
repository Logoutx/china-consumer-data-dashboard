# 候选数据源：高频脉搏与消费者信心（2026-08-28 调研）

这份文件回答 HANDOFF 里两条 “暂无数据来源” 的待办。结论先行：高频脉搏板块有 4 个可以纳入的官方来源（都是月度 HTML 新闻稿，没有 JSON 接口）；全国消费者信心指数应视为停更，不要为它建抓取。

## 高频脉搏板块

按接入优先级排序。共同点：都需要走 “轮询目录页 → 发现新发布 → 解析 HTML” 的新闻稿路线（与 nbs_retail 同一套路），没有类似 DG 的结构化接口；都无需登录，境内可直连。

1. **快递业务量** — ✅ 已接入（2026-08-31，`--source spb_express`，走交通运输部镜像，详见 docs/ACQUISITION.md Group 8）。国家邮政局，月度 “邮政行业运行情况”，次月 15-20 日左右发布。
   目录页：https://www.spb.gov.cn/gjyzj/c100015/c100016/ （交通运输部有镜像 https://www.mot.gov.cn/tongjishuju/youzheng/ ）。
   每期是独立 HTML 新闻稿，URL 含日期串不可预测，需爬目录页。历史存档多年。
2. **民航旅客运输量** — 民航局，月度，次月下旬发布。
   目录页：https://www.caac.gov.cn/XXGK/XXGK/TJSJ/index_1214.html （镜像 https://www.mot.gov.cn/tongjishuju/minhang/ ）。
   另有年度统计公报（PDF）可做历史回填。
3. **铁路客运量** — 国家铁路局/交通运输部，月度，滞后约两周。
   目录页：https://www.mot.gov.cn/tongjishuju/tielu/index.html （国家铁路局发布列表 https://www.nra.gov.cn/xwzx/xwxx/xwlb/ ）。
   注意：发布的是 “1-N 月” 累计数，单月值要用相邻两期相减，与现有 单月 = 累计差分 的推导规则同型。
4. **电影票房** — 国家电影局，月度/年度新闻稿。
   目录页：https://www.chinafilm.gov.cn/xwzx/gzdt/ 。全国月度总票房在免费新闻稿里；更细的数据在专资办的中国电影数据信息网（https://www.zgdypw.cn/ ），是否需要登录未验证，先不依赖。
5. **假期出游/旅游花费** — 文化和旅游部，**季度**（非月度），另有节假日专项稿不定期。
   目录页：https://zwgk.mct.gov.cn/zfxxgkml/tjxx/ 。出游人次 + 出游花费，分城乡。作为低频补充，不能当月度脉搏用。

建议接入顺序：先做快递 + 民航（单一指标、目录页稳定、月度最干净），再做铁路（要处理累计差分），票房第三，文旅季度数据最后。

## 消费者信心指数

- 全国指数在 DG 接口树里不存在，2023 年初之后也找不到官方发布的指数值——判定为停更/休眠，不建抓取。
- 统计局的消费者信心电话调查在省市层面仍在进行（只有调查启动公告，没有结果数据），说明调查体系还在，但结果不对外发布。
- 网上有一条 “2024 年 12 月消费者信心指数环比上升 0.2 个百分点” 的答记者问引文，未能核实原文，若要最终定论可再查一次 stats.gov.cn/sj/zxfbhjd/ 与 /sj/sjjd/ 的发布列表。
- 目前唯一还在更新的替代来源：北京大学国家发展研究院与百分点科技合作的月度 “中国消费者信心指数报告”（https://www.nsd.pku.edu.cn/xzyj/kyfb/zsfb/zgxfzxxzs/ ）。这是学术/商业来源，不是政府数据，与原统计局序列的可比性未验证——若采用，必须在页面上明确标注来源性质，且不能与官方序列拼接。
